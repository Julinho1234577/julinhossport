¿Con qué telas trabajamos?

Trabajamos con diferentes tipos de telas para ofrecer prendas cómodas, resistentes y adecuadas para cada necesidad.

Polialgodón

Cómodo, resistente y pensado para uso escolar diario.

Polinam

Opción práctica para confección de buzos escolares

Interfil grueso

Mayor abrigo para temporadas frías.

Franela

Tela suave y abrigadora, ideal para buzos, poleras y prendas para temporadas frías.

Taslán

Ideal para prendas cortaviento y casacas.

Piel de durazno

Cómoda para buzos y prendas deportivas.

Polar / Micropolar

Para prendas destinadas a mayor abrigo.

Poliéster

Tela resistente y de fácil mantenimiento, ideal para prendas deportivas y uniformes.

Drill

Tela resistente y de buena estructura, ideal para uniformes, casacas y prendas de trabajo.
